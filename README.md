# Soulframe Companion

Your desktop companion for **Soulframe** — collection tracking, instant answers,
and build planning in one place.

> Unofficial fan-made tool. Not affiliated with or endorsed by Digital Extremes.

## Download

**[Get the latest version →](https://github.com/ECL-Durden/soulframe-companion-releases/releases/latest)**

Grab the `-setup.exe`, run it, done — it keeps itself up to date from there.
Windows only for now.

## What you get

- **Track your collection** — pacts, weapons, armour, talismans. Tick off what
  you own; it persists between sessions. Hide the finished ones to see only
  what's left.
- **Know how to get anything** — obtention method, exact craft components, Drac
  cost and craft time, without alt-tabbing to a wiki.
- **Full material breakdown** — every source for every resource: which foes drop
  it, which containers and operations give it, which plants to harvest, how to
  craft it.
- **English & French**

## On the roadmap

- More companion tools as the game grows
